# Código de conducta

CajaDIY es un proyecto para gente que fabrica cosas: electrónica, impresión 3D, bricolaje. Queremos que cualquiera pueda preguntar, reportar un fallo o proponer una idea sin miedo, sea principiante o experto.

## Lo que esperamos
- Trato respetuoso y amable, aunque no estemos de acuerdo.
- Críticas sobre el programa o las ideas, nunca sobre las personas.
- Paciencia con quien recién empieza: todos imprimimos alguna vez una caja que no cerraba.
- Mensajes claros y con datos (qué hiciste, qué esperabas, qué pasó).

## Lo que no se acepta
- Insultos, burlas, acoso o ataques personales.
- Comentarios discriminatorios de cualquier tipo.
- Publicar datos privados de otras personas.
- Spam, publicidad o enlaces engañosos.

## Cómo se aplica
El mantenedor puede editar, ocultar o borrar comentarios, issues y discusiones que no respeten este código, y bloquear a quien lo incumpla de forma repetida.

Si ves algo que no corresponde, avísalo abriendo un issue con el título **«Conducta»** (sin repetir el contenido ofensivo) o usando la opción **Report content** de GitHub en el comentario. Los reportes se revisan con discreción.

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/), versión 2.1.
