# Cómo colaborar con CajaDIY

¡Gracias por querer ayudar! Este repositorio publica **solo el instalador** de CajaDIY; el código fuente no es público, así que **no se aceptan pull requests con código**. Hay otras formas muy valiosas de colaborar:

## Reportar un fallo
1. Revisa en [Issues](../../issues) que no esté reportado ya.
2. Abre un issue con la plantilla **«Reportar un fallo»** y cuenta:
   - versión de CajaDIY (menú **Ayuda → Acerca de…**) y de Windows;
   - versión de OpenSCAD;
   - los pasos para que el fallo se repita;
   - qué esperabas y qué pasó (con capturas si puedes).
3. Si el problema es con una caja concreta, **adjunta el perfil** (`.json` que guardas con «Guardar perfil»). Con él se puede reproducir exactamente tu caja.

## Proponer una mejora
Abre un issue con la plantilla **«Proponer una mejora»**: qué te gustaría poder hacer y para qué. Un boceto a mano o una foto ayuda mucho.

## Compartir plantillas y resultados
- Perfiles para placas que no están en la lista (Raspberry Pi Zero, Pico, ESP32-C3…): adjúntalos en un issue con las medidas comprobadas.
- Fotos de cajas impresas, con la impresora, el material y los ajustes que usaste.

## Traducciones
El programa está en español, inglés, polaco, alemán y francés. Si ves un texto mal traducido, indícalo en un issue con el texto actual y tu propuesta.

## Seguridad
Los problemas de seguridad **no** se reportan en issues públicos: ver [SECURITY.md](SECURITY.md).

Al participar aceptas el [Código de conducta](CODE_OF_CONDUCT.md).
